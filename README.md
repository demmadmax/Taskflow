# TaskFlow

A modern task management web application designed to help users organize, track, and manage their daily tasks efficiently.

## Features

- Create new tasks with a title and description
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Track pending and completed tasks
- Persistent task storage using browser LocalStorage
- Clean and responsive user interface
- Task statistics for quick progress tracking

## Tech Stack

- React
- TypeScript
- HTML
- CSS
- LocalStorage

## Project Overview

TaskFlow was developed as a productivity-focused web application that provides a simple way to organize daily tasks.

The application uses React state management to handle task creation, editing, completion, and deletion. Task data is stored in the browser's LocalStorage so that tasks remain available after refreshing the page.
